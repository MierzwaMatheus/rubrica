Rubrica 2.0.0: servidor MCP local (`rubrica mcp`) que substitui o script Python da skill `rubrica`. O agente edita páginas, blocos, coleções, textos, mídia e contatos pelo Convex do projeto, com o login de um usuário do painel (`rubrica mcp login`), respeitando o papel dele, e com prévia antes de gravar (`dryRun` ligado por padrão).
