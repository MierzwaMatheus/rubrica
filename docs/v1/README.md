# Documentação da v1 (arquivada)

> Estes documentos descrevem o **Rubrica v1** (template copiado para o projeto, SPA em Vite, 13 layouts). Eles ficam aqui só para consulta de quem ainda mantém um site v1, que recebe correções de bug e de segurança por 6 meses depois do lançamento da v2.
>
> Para o Rubrica v2, comece por [Começando](../guia/comecando.md). Para levar um site v1 para a v2, siga [Migrar da v1](../guia/migrar.md).

## O que tem aqui

| Pasta ou arquivo | O que era |
|---|---|
| `guia/` | Começando, CLI, publicar e telemetria da v1 |
| `templates/` | Um guia por layout da v1, esquemas de cores e como criar um layout |
| `atualizacao.md` | Como atualizar um projeto v1 (mesclando arquivos) |
| `features.md` | Lista de recursos da v1 |
| `cli-manutencao.md` | Manutenção do CLI da v1 |
| `mudancas-backend-conversao.md` | Notas de conversão do backend da v1 |

Os links entre estes arquivos podem apontar para caminhos que não existem mais. A v1 completa está na branch `v1` do repositório.
